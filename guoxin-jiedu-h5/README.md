# 国心解读 H5 移动端产品原型

这是一个结合东方文化视角、心理分析和生活建议参考的 AI 解读助手 H5 原型。

原型采用原生 HTML/CSS/JavaScript 构建，无需安装任何复杂的依赖。为了提供更好的演示体验，该原型在桌面端（Desktop）展示时拥有一个**模拟手机框**（iPhone 13/14 尺寸）以及一个**演示控制面板**，可自动适配不同的屏幕宽度，支持完全响应式的移动端全屏展示。

---

## 🛠️ 项目结构

```text
guoxin-jiedu-h5/
├── index.html     # 页面结构 (包含9个演示页面/状态)
├── index.css      # 设计系统、样式、动效与老年人大字号适配
├── assets/        # 本地 SVG 头像、纸纹、图标与背景资源
├── app.js         # 原型交互逻辑、本地缓存(LocalStorage)与数据生成器
└── README.md      # 本自述文件
```

## 🚀 启动与演示说明

您可以通过以下两种最简单的方法打开并体验原型：

### 方法一：双击直接打开（最快）
直接在文件管理器中双击打开 `index.html` 文件即可在浏览器中体验。

### 方法二：启动本地服务（推荐）
在终端中进入该项目目录，并运行以下命令之一：

**Python 3 (Mac/Linux 内置):**
```bash
python3 -m http.server 8080
```
然后打开浏览器访问：[http://localhost:8080](http://localhost:8080)

如本机 8080 端口已被其他服务占用，可改用：

```bash
python3 -m http.server 8090
```
然后访问：[http://localhost:8090](http://localhost:8090)

## 🎯 核心演示场景与特色

1. **温和可信的“国潮”东方美学设计**
   - 采用米白 (`#FDFBF7`)、墨绿 (`#1E3F35`)、浅金 (`#C5A880`)、暖棕 (`#F5EFE6`) 配色。
   - 视觉上更接近心理陪伴、生活建议和传统文化学习服务，避免夸张、神秘或强刺激表达。

2. **中老年人关怀（字号调节 Heuristics）**
   - 演示控制面板中提供了**“大字号”**与**“特大号”**切换。
   - 界面整体采用 `rem` 响应式排版，切换字号后，界面元素与文字大小协调等比例缩放。
   - 表单输入使用“关系选择片”、“性别选择片”、“时辰下拉框”，避免过多繁琐打字输入。

3. **完整的 AI 深度整理模拟**
   - 点击“确认开始解读”后，页面将展示简短预览，并开启 4 阶段的进度条，模拟后端持续整理和生成完整解读的过程。
   - 演示控制面板中提供了 **“跳过等待，直接完成整理”** 的快捷键，以便瞬间跳过 10 秒的模拟等待，弹窗显示生成完成。

4. **动态完整解读生成**
   - 完整解读并非纯静态文本。系统会根据所选心语档案的**姓名/称呼、与我的关系、年龄性别**以及在心语老师引导中点选的**关注方向**（例如家庭关系、情绪状态、健康作息等），在前端拼接生成一篇结构完整的生活与心理参考内容。

5. **数据本地持久化 (LocalStorage)**
   - 登录态、创建的档案、解读历史记录与次数余额将自动保存在您的浏览器本地，刷新页面数据不丢失。
   - 默认解读次数为 3 次；当次数为 0 时，点击“确认开始解读”会进入开通解读权益页。
   - “开始我的专属解读”会先弹出心语档案选择层，选择档案后再进入心语老师引导流程。
   - 提供控制面板中的“清空缓存 & 恢复默认数据”按钮，可一键复原演示状态。
