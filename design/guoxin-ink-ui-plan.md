# 国心解读全项目水墨风 UI 重构计划

## 一、不可变边界

- 以当前仓库页面、组件、路由、状态与文案为唯一依据。
- 不新增、不删除、不合并功能；不改变接口、Store、支付、登录、建档、问答、报告生成与跳转逻辑。
- 不删减、不改写页面标题、说明、按钮、占位文案、提示、协议正文和异常文案。
- 允许调整视觉布局，但每一个现有操作入口、字段、状态和反馈必须保留。
- 水墨人物、远山、竹叶、云纹仅作背景或装饰，不承载新功能。

## 三、共用组件改造

1. `GxChatHeader` / `GxNavBar`：由大面积红色渐变改为宣纸浅底、墨色标题、朱砂小面积状态强调。
2. `GxCard` / `GxButton` / `GxChip`：统一暖白卡片、细茶金边框、18–24rpx 圆角和低阴影。
3. `GxChatComposer`：保留附件、输入、发送全部交互，改为纸面悬浮输入条。
4. `GxAvatarSwitcher`：保留当前用户、切换和添加，视觉改为印章头像与浅墨选中态。
5. 登录、八字信息、邀请、客服、额度不足与反馈弹窗：统一遮罩、标题、表单和按钮体系。
6. 报告组件：保留动态渲染结构、图表和字号能力，统一宋体章节标题、宣纸分隔和朱砂章节标识。

## 四、设计规范

- 页面底色：`#F7F0DF`
- 卡片底色：`#FFF9EC`
- 主文字：`#34271F`
- 次文字：`#746657`
- 朱砂强调：`#A94B32`
- 赭金强调：`#B47A2C`
- 雾蓝灰：`#DCE5E2`
- 竹叶青：`#A8B99A`
- 边框：`rgba(126, 101, 67, 0.22)`
- 标题使用宋体/明体语气，正文与表单保持高可读无衬线字体。
- 水墨背景对比度控制在 8%–18%，不得影响正文、按钮和表单识别。

## 五、实施顺序

1. 建立主题变量、宣纸背景和字体层级，先覆盖共享布局。
2. 改造公共导航、卡片、按钮、表单、弹窗和输入区。
3. 改造问答主流程：问答 → 确认生成 → 整理中 → 完成 → 报告详情。
4. 改造档案与八字用户流程，包括空状态、编辑与删除确认。
5. 改造权益、会员、支付成功和客服弹窗。
6. 改造我的、协议长文及所有异常/加载/额度状态。
7. 执行 H5 构建、类型检查、关键交互回归、375/390/430 宽度视觉检查。

## 六、验收清单

- 路由数量、入口数量、按钮数量、表单字段数量与改造前一致。
- 所有原文逐项比对，无删减、无改写、无新增营销文案。
- 登录、建档、用户切换、问答、图片附件、报告生成、支付和客服链路可用。
- 未登录、空列表、加载、生成中、成功、失败、次数耗尽等状态均有对应 UI。
- H5 与微信内置浏览器安全区、滚动、选择器和弹窗层级正常。
