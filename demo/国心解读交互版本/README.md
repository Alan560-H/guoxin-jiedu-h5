# 国心解读 H5 设计稿

这是一个静态 HTML/CSS/JS 交互原型，用于展示“国心解读”八字问答、报告和会员购买流程。进入后先看到对话首页，登录前可浏览，登录后才能发起问答。

## 设计方向

- 使用丙火红、暖金与米白色调，保持克制的传统文化质感
- 首页就是对话页，用户点击问题后用弹窗判断登录
- 将原“档案”统一为“八字用户”，支持新增、编辑、删除和切换
- 首页与聊天页使用头像列表直接切换八字用户，当前用户显示红金选中态，右侧固定“＋添加”
- 对话中的用户头像跟随当前八字用户称呼首字，Agent 固定使用“知”
- 每条 Agent 正式回答提供“有帮助 / 需改进”反馈，可补充具体原因
- 没有八字用户时原位提示添加，保留邀请好友入口；第一位默认关系为自己，后续新增默认家人
- 八字使用组件选择性别、历法和地点；出生日期与时间通过一个完整选择框一次选择，并支持“时辰不确定”与真太阳时
- 支持分享邀请链接；好友先看邀请说明，点击填写后先登录，再填写八字并授权提交
- 报告会按当前八字用户的历史问题提取关键词，并作为生成时的解读重点
- “我的”页面提供客服入口，覆盖会员开通、权益问题与报告售后
- 登录免费用户每日可问 3 次，次日 00:00 恢复 3 次
- 对话记录跨天保留，第二天可在原问题上继续聊
- 问答头像左右分工：AI 固定显示“知”，用户头像显示当前八字用户称呼首字
- 首页推荐问题和每轮追问方向均支持“换一批”
- 当日次数用完后引导开通不限次问答套餐
- 聊天页提供独立套餐入口；套餐页展示今日优惠倒计时、原价和限时价
- 不同套餐的客服购买弹窗会同步对应名称、价格、有效期和报告额度
- 权益页提供单次报告额度购买入口，单次额度与问答套餐有效期分开保存
- 权益页以丙火红与暖金为主色，顺序为 9.9 新人体验、年包、季包、月包、会员专属次数包
- 倒计时只在 9.9 新人体验大卡展示；9.9 单次报告次数仍仅限有效会员购买
- 套餐支付页顶部红色区域作为会员详情入口，点击进入独立权益对照页
- 会员详情页先选择新人首单、月度、季度或年度套餐，再提示联系专属客服购买
- 新人首单、月、季、年和单次报告加油包展示折后价及划线原价
- 客服购买弹窗展示真人确认、付款方式说明和开通进度可查，点击后跳到客服承接页
- 右上角为“我的”，个人页包含头像昵称和“我的报告”
- 登录改为弹窗：用户首次点击开始对话或进入“我的”时判断登录，登录后不反复打断
- 登录提示文案为“还差一步即可和 AI 对话聊天”
- 追问后提供多个引导问题，每个问题都有用途说明，聊天页底部保留推荐报告广告位
- 报告入口使用“生成完整命理解读报告”文案，并说明会结合八字与问答内容整理
- 生成报告优先复用问答时已保存的八字，只有资料缺失时才重新采集
- 问答次数与报告额度独立计算；普通问答不扣报告额度，确认生成报告时才扣除
- 权益套餐按会员权益表重排：登录免费权益、月卡、季包、年包、会员专属单次加油包
- 覆盖问答、资料采集、购买、确认生成、生成中、报告列表、报告详情

## 打开方式

直接双击 `index.html`，或在浏览器打开：

```text
/Users/admin/Desktop/ai编程/outputs/mingli-agent-h5/index.html
```

需要重新体验时，在地址后加 `?reset=1`，页面会清除登录、问答、八字和已购权益后回到首页。

测试发放 10 次报告额度：访问 `?grant=report10-20260722`。同一浏览器只执行一次，成功后自动进入“我的”；正式环境必须改为后端权益发放接口。

## 独立会员充值 H5

打开 `recharge.html`。该页面不读取第三方 App 登录态，用手机号验证码绑定国心解读 H5 账号，会员有效期与报告额度都归属该账号。

```text
http://<LAN_IP>:4173/recharge.html
```

当前为静态交互原型；正式上线时需将验证码、微信支付和权益到账替换为服务端接口。
需要重新体验时访问 `recharge.html?reset=1`。
